# Outputs・Projectsの閲覧性改善

2026-09-08にユーザーが改修方針を承認し、実装開始を指示。

## デザイン

- 既存の紺・青の配色を継承。Outputsの先頭でAIの実践と知見共有を紹介する。
- AI駆動開発に関するQiitaの前後編を代表記事として固定掲載し、yt-factoryの実践にも誘導する。未確認の閲覧数・反響数は掲載しない。
- Qiita・Blog・noteの最新3記事を公開日順に表示。スマホは縦並び。長い記事名の可読性を優先し、Qiitaに不要なダミーサムネイルを置かない。
- 記事取得失敗・空の場合も媒体名とリンクを残し、最新記事は媒体で確認できることを伝える。
- Projects詳細は白地に紺の見出しを使い、タイトル・要約、構成図、詳細本文の順とする。本文は読みやすい幅を保ち、図は広く表示する。
- モーダル上部の閉じる操作をスクロール領域から分離。スマホでは全画面にする。
- すべてのプロジェクト画像はボタンで拡大可能。全画面ビューアで全体表示・ズーム・スクロール・元画像リンクを提供する。
- キーボードでカードと画像を開ける。Escは最前面のビューアのみ閉じ、元の操作位置へフォーカスを戻す。

## 実装方針

1. 既存の記事取得インターフェースを維持し、XMLパーサーを用いてRSSとAtomを正規化。公開日・URLを検証し、取得を24時間キャッシュする。
2. Outputsから記事パネルとYouTube部分を分離し、AI紹介と記事一覧をその前に配置する。
3. 既存MUI Dialogを利用してプロジェクト詳細と画像ビューアを構築する。本文は既存Markdownを使用し、共通の見出し・リスト・表・コード表示を整える。
4. XMLフィードの回帰テスト、型チェック、lint、ビルド、実ブラウザでPC・スマホ表示とキーボード操作を確認する。

## 対象範囲

ホームのOutputsとProjects詳細モーダルが対象。既存コンテンツと画像を再利用する。専用プロジェクトページへの全面移行や未確認の実績数の追加は行わない。
